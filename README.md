# NF GROUP — NF Hub

React + TypeScript + Redux Toolkit + PWA + Tauri. Демо-витрина рынка ЦОД (условные числа, сделки из открытых СМИ), ссылки на публичный архив NF MAGAZINE и отдельный Python-проект мониторинга.

## Загрузка на GitHub

1. Создайте репозиторий `nf-group-projects` с веткой `main`.
2. Загрузите СОДЕРЖИМОЕ этой папки в корень репозитория: README.md, web, projects, .github и остальные файлы. Не загружайте ZIP одним файлом.
3. Settings → Pages → Source → GitHub Actions.
4. Actions → Publish NF Hub to Pages → Run workflow (если публикация не началась сама).
5. После успешного запуска откройте адрес в Settings → Pages.

Папка .github скрытая в macOS: показать скрытые файлы можно Cmd+Shift+точка. Она обязательна для автоматической публикации. Для большого числа файлов используйте GitHub Desktop: добавьте папку, создайте commit и нажмите Publish repository.

Имя репозитория подставляется в путь автоматически при сборке в Actions. Для репозитория вида USER.github.io нужно изменить PAGES_BASE в workflow на /.

## Папки

- web/src — приложение NF Hub, фильтры Redux, карточки игроков и журнал.
- web/src-tauri — исходники и настройки Tauri.
- projects/media-monitor — Python-сборщик с отдельной инструкцией.
- deployment_nf.* — присланная диаграмма; сервер на ней является планируемым.
- .github/workflows/pages.yml — сборка и публикация Pages.

## Запуск локально

В web: `npm install`, затем `npm run dev`.
Для Tauri: установить Rust и системные зависимости Tauri, затем `npm run tauri dev`.
Адрес API задаётся в web/.env по образцу .env.example; разрешённый адрес в CSP Tauri нужно согласовать с ним.
Для проверки сборки: `npm run build`.

## Статус и ограничения

Архив объединяет исходники из присланного проекта с ранее подготовленными журналом и мониторингом. Он не опубликован автоматически.
API и БД отсутствуют: приложение использует mock при ошибке API. IP 192.168.1.50 — пример. HTTPS API не настроен. Redux сохраняет фильтры при переходах, но не после перезагрузки. Для Pages используются hash-маршруты, чтобы прямые ссылки работали без серверного роутинга.
Полная сборка React и запуск Tauri при подготовке архива не проверялись. После установки зависимостей необходимо проверить сборку и демонстрационный сценарий.
База знаний с контактами, тексты статей и веб-архив корпоративного журнала в репозиторий не включены: журнал предназначен только для внутренней коммуникации (дисклеймер в выпуске №22).
